# Vrishna - Luxury E-commerce Template

This is a premium, minimal, contemporary front-end template designed for Vrishna.com.

## Features
- **Responsive Design:** Mobile-first approach.
- **Modern Animations:** Built with AOS (Animate on Scroll) and CSS Keyframes.
- **Glassmorphism:** Navigation and overlays use modern blur effects.
- **Static Deployment:** Ready for GitHub Pages.

## How to Deploy to GitHub
1. Create a new repository on GitHub named `vrishna-web`.
2. Clone it to your computer.
3. Move these files into the folder.
4. Commit and push:
   ```bash
   git add .
   git commit -m "Initial launch of Vrishna"
   git push origin main
